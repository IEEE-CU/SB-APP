# QA-03: unit-test count gap (645 declarations vs 718 executed)

Static analysis only. No test, harness, or command that runs tests was executed.

## Inspected
- `D:\SB-APP-worktrees\combined\backend\test\unit\*.test.js` (48 files), searched with Grep.
- `completion\raw\combined\backend-unit.raw` (820 lines), including its summary lines.

## Result: the gap reconciles exactly (645 + 73 = 718)

1. **645 is the count of line-start `test(` declarations** (regex `^\s*(test|it)\(`), across 48 files. There are no `describe`/`suite`/`it` blocks. The files use only `node:test` `test(`.
   - `test.after(` hooks (15 of them) are not counted in 645 and do not execute as tests.
   - The raw summary shows `tests 718, suites 0, pass 718, fail 0, skipped 0, todo 0`.
2. **Three files declare tests inside a top-level `for` loop over a data table.** Each declaration runs once per table row, so these files execute more tests than they declare.

| File | Declarations (loop-body / total) | Table rows | Executed | Extra |
|---|---|---|---|---|
| society-access.test.js (`SOCIETY_ID_ROUTES`, loop at line 85) | 5 / 15 | 11 | 10 + 5×11 = 65 | +50 |
| finance-workflow.test.js (`ROUTES`, loop at line 218) | 2 / 24 | 9 | 22 + 2×9 = 40 | +16 |
| importers-authorization.test.js (`ROUTES`, loop at line 161) | 7 / 11 | 2 (`/todoist`, `/slack`) | 4 + 7×2 = 18 | +7 |
| **Total** | | | | **+73** |

645 + 73 = **718**, which matches the runner.

## Other loops checked and ruled out
- `script-import-safety.test.js:58` and `opportunity-scraper-urls.test.js:28` are setup loops. They contain no `test(` calls and generate no tests.
- `community-hub-scope.test.js` (lines 157, 182, 204) and the inner `for` loops in `importers-authorization` and `finance-workflow` sit inside a single test body. They add assertions, not tests.

## Not reconciled / limits
- **Per-file executed counts from the raw file:** `backend-unit.raw` has per-test lines (`✔ name (ms)`) but no file names. I did not map every line to its file. The per-file executed counts above come from declarations × table rows, not from the raw output.
- **Spot check against the raw output:** a pattern search for `AUD-018 `, `denied without` and the `/todoist:` and `/slack:` prefixes returned 80 lines. I expected 55 + 9 + 14 = 78 from the loop-generated tests. The search pattern was approximate, so 80 versus 78 is not exact and I did not examine the 2 extra lines. This does not affect the arithmetic above, which depends on the declaration and table counts.
- I did not verify that the raw file contains each loop-generated test name the expected number of times.
- Nothing was found that suggests missing, skipped or duplicated tests.
